# Gizoogle (Local)

Yo GitHub - welcome to **Gizoogle (Local)**. This extension takes the *visible text* on whatever site you're on and remixes it with a Snoop-inspired, West Coast flavor.

Everything runs locally in your browser: no cloud calls, no text uploads.

## What it does

- Translates visible page text (and keeps up with dynamic pages as they change).
- Skips stuff that should not get touched: `code`, `pre`, form fields, and editable text.
- Gives you a popup with an on/off toggle and a **Snoopiness** slider (levels `1` to `3`).

Snoopiness levels:
- `1` = light touch
- `2` = standard flavor
- `3` = extra saucy

## Install (Chrome / Edge) - beginner friendly

1. Download this repo (green **Code** button -> **Download ZIP**) and unzip it somewhere easy (like your Desktop).
2. Open your browser's extensions page:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. Turn on **Developer mode** (usually a toggle in the top right).
4. Click **Load unpacked**.
5. Select the folder that contains `manifest.json` (this repo folder).
6. Optional: pin it (puzzle-piece icon -> pin **Gizoogle (Local)**).

To uninstall: extensions page -> **Remove**.

## Use it

1. Click the extension icon.
2. Toggle it on/off, and set your **Snoopiness** level.
3. Refresh the tab if you want a clean re-scan.
